# Model Arena

A production AI evaluation system that tests multiple models on the same task and compares their accuracy,latency, and reliability

## Models
- qwen3:8b (local, Ollama)
- gemma4:e4b (local, ollama)
- gemma4:26b (local, Ollama)
- claude-haiku-4-5 (cloud, Anthropic API)

## Stack
Python 3.12, Pydantic, FastAPI, PostgreSQL, SQLAlchemy, Next.js, Tailwind
